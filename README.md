# Expense Tracker

Автор: Ваше Имя Фамилия

## Описание
Это простое GUI-приложение для отслеживания личных расходов. Позволяет добавлять расходы с указанием суммы, категории и даты, фильтровать их по различным параметрам и подсчитывать общую сумму за выбранный период.

## Как использовать
1. Запустите файл `expense_tracker.py`.
2. Введите сумму, выберите категорию и дату, нажмите «Добавить расход».
3. Для просмотра — расходы появятся в таблице.
4. Для фильтрации — выберите категорию или введите даты, нажмите «Применить фильтр».

## Пример использования
- Добавление расхода:
  - Сумма: 150
  - Категория: Еда
  - Дата: 2024-05-01
  - Нажать «Добавить расход»

- Фильтр по категории «Еда» и дате с 2024-05-01 по 2024-05-31.
